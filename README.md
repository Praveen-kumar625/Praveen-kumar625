# 🧠 Engineering Philosophy

> **Build with purpose. Validate with evidence. Engineer for reality.**

My approach is centered around a few principles:

**Problem First**  
Understand the actual problem before choosing the technology.

**Architecture Before Complexity**  
Keep systems modular, maintainable, and easier to evolve.

**User Experience Matters**  
A technically powerful system is not useful if users cannot understand or operate it.

**AI Should Be Useful**  
Use AI where it provides measurable value rather than adding AI simply for the label.

**Reliability Over Hype**  
Prefer robust engineering decisions over unnecessary complexity.

**Continuous Learning**  
Every project is an opportunity to improve engineering depth.

# 🚀 Featured Projects

## 🌦️ WeatherGPT India

### Conversational AI for Weather Intelligence

A weather-focused conversational platform designed to transform meteorological information into **clear, contextual, and actionable intelligence**.

### What I’m Building

- Conversational weather queries
- Weather forecasting and alerts
- Location-aware intelligence
- Role-based personalization
- AI-assisted weather explanations
- Interactive weather visualization
- Grounded responses using verified data sources
- Multilingual interaction

### Engineering Focus

**Reliable data → structured processing → AI reasoning → useful response**

The goal is to prevent the AI layer from becoming a source of fabricated weather information by grounding responses in externally retrieved weather data.

**Focus:** AI Engineering • Full Stack • Data Grounding • UX
